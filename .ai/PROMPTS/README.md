# Prompts — Reusable AI Instruction Snippets

> Store reusable prompt fragments for common agent interactions.
> Each file in this directory is a self-contained prompt for a specific scenario.

---

## Usage

Reference prompts by path: `.ai/PROMPTS/<name>.md`

When starting a task, agents SHOULD load the relevant prompt template
in addition to the core `.ai/` files.
